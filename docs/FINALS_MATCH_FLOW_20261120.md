# 决赛比赛流程与异常处理

[打开可离线缩放及分图打印的完整流程图](FINALS_FLOW_ATLAS.html)。图共八张，覆盖正常动作、判断条件、重试及失败出口。

决赛上位机本地提交 `c648cdc`，基于 `71d199a` 的 1121 模型。对照初赛上位 `2e336f8`、下位 `2ff1ba0`；下位最新差异为决赛排除的黑蓝专用动作调速，本版继续使用已验证的 FinalRun 执行逻辑。

| 阶段 | 正常动作 | 常见异常及出口 |
| --- | --- | --- |
| 发车 | 确认阵营、出发位和策略，完成原发车配置；后退 0.60 m、转向、按轮程前进 1.10 m，再进入视觉找物。 | 等待有效配置。保局重发按已有任务进度恢复，暂停期间不把旧回包算作新动作完成。 |
| 开局首放 | 启用开局暂存时，识别、抓取、复审后按策略运到放置点。防守放下后退 350 mm，直返①；进攻在放置点朝对方安全区转正、放下，退 100 mm，再按本段轮程横移、返回①，最后转向搜索。 | 暂存不计首件。移动需要定位时，定位无效先等待；进攻横移按首包与轮程完段，其余站点移动按约定的到点回包交接。 |
| 正式搜物 | 首件必须合法单绿；首件确认后按核心、普通、伤员优先，同类就近。①、③轮换，本站累计扫满 540° 无目标才换点。 | 目标暂失按原跟踪与恢复流程找回；搜索换点粗段锁初始方向用轮程，末 350 mm 用实时定位精靠。 |
| 靠近与抓前复看 | 对准目标并测距，远段最高 1000 mm/s；到近处用 140° 看爪区。条件满足时可走 50 mm 补进。 | 首次定距前远绿、远橙疑似在区内，可原地用 105° 新图复审，确认在区外才继续；原目标认不回、140° 确认空爪且有合规替代目标，发 U=5 回 120° 原地重选。无有效证据走原等待、恢复或弃批出口。 |
| 合爪与分离 | 上位提交真实组成并配对审核。首件后，1～3 件纯材料（绿／黑，可混合）送物资区；单橙送伤员区。单侧释放或带侧分离时，保留爪以 40°/秒额外夹紧 20°，保左 64°、保右 116°，两爪到位再等 260 ms。 | 蓝块算危险物，爪区重叠门槛 40%，还须满足底边中点条件。普通蓝绿等符合条件可 ±10° 试转，看到分居中线可提前停车，再用新图决定。停稳后若一绿一蓝各归一爪，即使框仍跨中线，也按真实绿侧保留。若同侧前后叠、绿近蓝远且蓝的横向偏移明确，本批只拨一次：蓝偏右保左，蓝偏左保右；两侧真实计数原样上报，动作完成后再取新图。单黑单蓝沿普通分离／弃批处理。首绿仍可见最多五次实际分离，第五次后若已成合法单绿仍可抓；其余按连续无进展次数退出。抓后无抬高倒退过滤。 |
| 持载与门口 | 确认载荷后导航到对应安全区，转正、视觉对准、检查通道，再准备推入。停稳复审内保留真实混装证据；跨任务或复审阶段换用本次证据。 | 门口发现黑块影响首绿资格时撤回资格，闭爪回 140° 重审；单橙旁持续跟随绿块会要求门口实审。可侧挤的通道障碍走侧挤并按实测前进量抵扣；需扫障时按原暂放、清障、找回与再次审核流程，未找回不能算已送。 |
| 推入、开爪、确认 | 累计入区 400 mm 时停车，调到 83°，等舵机估时结束再以 330 mm/s 盲推，合计目标 670 mm。首件后的两件或三件合法材料需要重推时，开爪退 100 mm、降到 86°、再推 150 mm，最多一次；整批视觉确认可提前结束。 | U=0 代表视觉确认，须完成本次开爪退出才登记。U=1 或下位 ENTER 自主超时走未确认撤离，不新增首件或已送件；重复动作不重复登记。退出后回对应搜索点继续。 |

普通识别失败优先复看、重选或弃批。下位报告故障、人工停车或上位审核交接达到故障超时，则走原暂停、停车或 ABORT 分支；不能凭上一批 DONE 继续当前动作。

**交付与验证。** 上位代码已本地提交，向其远端推送时当前账号收到 403。[上位补丁](contracts/rdk_finals_f405_flow_20261120.patch) 在决赛上位仓库 71d199a 以 git apply 应用后，得到与 c648cdc 相同的源码树。测试使用相机／加速器接口替身，未启动车辆或推理硬件。本轮 28 项上位定向回归通过，下位实跑状态机替身通过左右拨分及重发检查；此前扩展回归中有 8 项旧基线也失败，包括旧测试的状态／航路预期和环境依赖。下位通过协议构帧、生产状态机的抓前重选及重发、重推资格、送达／未确认／重发检查。实车尚未部署和烧录。
