# 决赛单件运输适配范围

历史方案。当前决赛采用[初赛正式流程迁移](CROSS_REPO_REQUESTS.md)。

2026-11-19。决赛每趟最多运一件，首要目标是稳定把一件普通物资送入本方物资区并确认进区。比赛流程以现场发布规则为准，类别按普通、核心、伤员和危险区分。改动在决赛上位机和独立的决赛下位机仓库中实施。

两端源码已接入单件运输。下位 `Final_Run/Final_task@4d14c19` 启用 `APP_FINALS_SINGLE_ITEM=1`，上位联调分支同步普通抓前、抓后、预备点、恢复、开局暂存和扫障取货。19 项上位相关检查通过，另核对了视觉扫障构帧和伤员搜索函数。板端实际版本和整车效果待验。

上位 `389c34f` 摘除旧门口滤除和撞堆入口，橙黑普通分离及单侧释放使用 `U=0`。下位 `FinalRun` 预设已经关掉抓后自动滤除。沿用原左右爪分离、整爪复审和安全区对齐。

## 第一阶段　停用抬爪滤除，统一左右夹爪分离

普通圆柱和核心圆锥台标称都高 60 mm，横放时最大直径同为 40 mm。旧动作无法凭高度保证筛掉哪一件。按以下入口逐个停用，待上下位联调通过后再清理无引用的旧状态和常量。

| 路径 | 决赛改动范围 |
| --- | --- |
| 下位自动滤除 `mode50` | 停用 `task_single_filter_eligible` 触发的 82°、后退 100 mm、恢复运输高度。覆盖首件单普通、单伤员、首件后两件或三件且至少两件普通，以及通过同一入口进入的扫障取回。合法单件接原运输或扫障取回完成出口，必要的重新合爪保留。 |
| 上位保伤员拆核心的特殊分离 | `_arm_disperse` 和 `_arm_invalid_release` 都使用原普通分离的 `U=0`。下位决赛路径统一使用普通分离姿态，取消为这条特殊分离保存、延续和恢复的 82° 状态。 |
| 门口伤员与核心混装的横移滤除 | 停用 `ORANGE_GATE_FILTER`。覆盖上位触发、执行等待和拒绝恢复，以及下位转正、横移、降爪、移回和该批次的特殊高度记忆。预备点复审发现混装时走原选侧分离和复审。普通安全区对齐横移属于独立动作。 |
| 首件普通分离失败后的直推物料堆 | 决赛停用 `FIRST_GREEN_BUMP`。危险球容易被碰滚。侧别不清时沿用原观察和退出路径。观察转向只用来恢复可判断的画面。 |

侧别和保留对象明确时，复用原 `DISPERSE_PILE` 或单侧释放的左右爪动作。动作完成后用原整爪审核确认实际类别、数量和去向，清掉动作前的载荷资格。保留侧、命令接受或下位 `DONE` 都只说明动作意图或执行结果。两件都在同侧、看不清或连续分离无进展时，沿用原有限尝试和放弃出口。

检查点只看三条代表路径。首件单普通和单伤员合法审核后直接交接原运输。预备点伤员与核心左右分开时，只发普通选侧动作，随后根据复审结果决定继续送、改目的地或放弃。仍能观察到混装时不能沿用分离前许可。

## 第二阶段　把单件要求落到所有转运入口

首趟正式送达要求恰好一件普通物资。之后普通、核心和伤员各走自己的单件运输流程。危险目标、类别不明以及仍有两件或以上的载荷走现有分离或放弃出口。决赛里无需保留初赛多件运输的选侧偏好。审核仍须如实报告所有可见物料和真实数量，才能按实际情况分离。

- 上位普通抓前、闭爪复审、预备点复审、扫障找回、已确认载荷复用和暂停恢复，核对单件条件是否一致。先前只确认过一次的单件资格，仅在原路径允许的同一闭爪批次且没有矛盾证据时可继续使用。开爪、分离或出现第二件后按原审核重新确认。
- 下位同步采用相同的运输合法性，覆盖普通抓取、运输、恢复和扫障后交接。旧混装数量编码仍可用于如实记录和分离，保持现有 UART 布局、动作配对和审核接口。
- 开局暂存沿用原类别规则，数量改为恰好一件。开局多件和普通多件走原分离或退出。旧视觉扫障取障仅对单件发合爪，mode43 的非法审核沿下位原超时回搜索。mode45 找回原货的非法审核发原放弃命令。决赛 `CLEAR_SAFE_ZONE` 只支持 A=0 的视觉取货。正式入口的推土机扫障路线、普通和伤员区判定保持原行为。

检查点以单件普通能正常进区、两件普通及普通加核心不会获得运输许可、危险或不明目标无法走投送为主。抓前和抓后结果一致时复用现有交接，沿用原动作超时和有进展才继续的分离规则。

## 第三阶段　用实物标定并验收首件得分

先用现场普通圆柱的立放和横放检查 105°/120° 接近距离、140° 爪内边界及运输时是否滚出，再补核心圆锥台和危险球。用一普通一核心左右各一件核对分离后剩余物料，用贴爪的危险球核对漏框。优先验证一件普通物资从识别到完全进入本方物资区的整条路径。现场模型、手工标定和判定阈值根据证据逐项修改。
