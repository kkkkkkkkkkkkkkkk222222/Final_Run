# FinalRun2 定位投送配套：修改与验证

2026-11-22，上海时间。基于冻结上位 `28deaa6861c0208adf4b00c125d213c687bd2a95`，开发分支 `finals-material-push200`。配套下位为 `Final_Run/FinalRun2-material-push200`，不是封存 FinalRun。未部署 RDK、未更新模型、未烧录或发车。

## 已实现的修改

- 普通运输按已确认的 C→A→M/H 分段。红 C=(0,300)、A=(0,770)、M=(-160,770)、H=(160,770) mm；蓝旋转180°镜像。每段先发 D=0，再消费本动作 ACCEPT|DONE；切段、补位、重新正对均分配独立动作号。H/D 的正常更新不重启动作。
- M/H 起推前单独检查定位横差≤10 mm、纵向±50 mm和航向误差≤1°，等待真实正对动作完成。图像横差不再生成底盘横移；安全区识别、115°复看、入口判障和视觉送达继续保留。丢框、侧挤返回、拒绝恢复不会恢复视觉横移。
- ENTER 在发布前锁存实际出发位置对应的前段和末段距离：前段 `max(0,970-depth)`，末段 `max(0,min(270,1240-depth))`，单位mm。名义200+270；前段结束由下位等83°机构行程，再推末段。同动作重发不改距离，侧挤后的实际位置不重复扣轮程。
- 退出后普通返程经对应 M/H→A→C，再接原搜索点。送走挡路同类、仍有原货暂存时只回M/H→A，再接原货观察位置，不走普通返搜。抓到挡路材料后的投送经A→M，不从A直接推入。
- 横扫固定只用W1：M/H保持围栏朝向先横移A；右转、放货，不先前进200；倒退160到M，左移100，倒退400，左移40到W1，再扫1000。蓝方镜像。保留原同类抓送的暂存动作；本次取消前进200仅指横扫分支。
- 默认防守。普通主动搜索只选材料；伤员识别、混装分离及门口判障仍保留。单伤员也不正式投送；误抓或分离后只剩伤员，沿原弃批动作张爪、后退300mm，再按既有规则转向或返搜，不计送达。混装分离保留材料侧，开局移堆及清障临时处理保持。

不把模型示意当实车外廓或轨迹。已确认的A点窗口角接触风险仍存在；本次没有为它额外收位、改道或加停车条件。

## 两端接口

沿用15字节帧、任务号/动作号和完成回包，不增加握手或计时资格。

| 命令 | 新配套内容 | 完成语义 |
| --- | --- | --- |
| 0x03 STAGE NAV | 每段独立action；D=0结束本段；同action的迟到正距离不重开已完成段 | 本段D=0实际处理后，原mode10/DONE |
| 0x04 ALIGN | 非视觉、A=0、B=0或11500，U红9000/蓝27000 | 下位真实航向≤1°并完成原相机等待后mode11/DONE；不伪装visual完成 |
| 0x05 ENTER | VALID/DRIVE_STRAIGHT/USE_FINAL_HEADING/DISTANCE_VALID，可加RED；A前段0..5000，B末段0..270，U本方航向 | 受理不代表送达；实际推入、开爪/观察、视觉确认和退出分别沿原回包 |
| 0x14 step6 | 新增本方围栏航向U=9000/27000，用于持载到A；已放货后的步仍用扫向0/18000 | 同action实时D/H，D=0且物理执行完成 |
| 0x14 step3 | 新增A=-160，保留旧-200 | 原定距完成；重发不重启 |
| 0x17侧挤 | 可从真实非视觉ALIGN完成入口进入 | 三段都完成才DONE；故障不冒充完成，原失败回包保留 |

旧无距离ENTER仍可被FinalRun2接受并按旧400+270执行；封存FinalRun不支持新距离ENTER，不可混用。

## 实际验证与范围

- `competition_rescue/tests/test_pose_delivery.py`：红蓝分段动作号、旧/未完成回包、10mm与1°边界、锁框/新走廊、失框115°、发布后距离锁存、W1镜像及普通/原货返程。
- 下位 `tools/check_finalrun2_pose_pair.py`：实际上位发布→生产C解析/Task→真实CRC回包。14个距离边界报文；8条红蓝材料的名义/20mm补位及确认/未确认投送；4条危险物/伤员挡路的完整W1横扫；4条抓取点/门前单伤员弃批。所有场景使用真实CRC回包，轮程和图像为模拟输入。
- 下位 `tools/test_finalrun2_pose.c`：8组推进长度；1°边界；83°等待；重复、参数变更、旧action、暂停恢复、新NAV清旧DONE；侧挤三段及不重复抵扣；旧ENTER与会话重置。已复现并修复“同action在D=0完成后收到迟到正距离会重新运动”。
- 既有 `check_finals_rdk_pair.py` 的实际载荷、分离、抓后复审、旧命令拒绝、确认/未确认完成回包兼容检查通过。

这些是离线测试。相机/YOLO/定位设备、轮滑、惯性、真实83°高度和带货扫掠未验；现有硬件失败、无有效画面、无定位或人工暂停仍会按原出口等待/退出。不能据此承诺实车永不卡住。

两端由本聊天先后实现并各自核对生产代码；未把同一实现者的核对称为独立互审。实际部署SHA、板端actual与实跑验收仍待现场记录。
