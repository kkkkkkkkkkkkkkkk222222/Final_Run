2026-11-22 当前开发配套为 **finals-material-push200 / FinalRun2-material-push200**：已按确认方案实现分段运输、定位正对和无视觉横移投送，默认防守，正式投送仅材料；前段200mm、末段270mm。伤员仍参与识别、混装分离和扫障，单伤员沿原弃批动作退出。[修改、接口与验证](POSE_DELIVERY_20261122.md)。未部署RDK、未烧录。以下是冻结28deaa6的既有规则，动作接口以新说明为准。

已对照定稿初赛 `2e336f8` 和决赛下位 `Final_Run/Final_task@0236947`。决赛使用自己的模型、标定和比赛入口。

- **首件记分**。第一次正式投送只接受一个普通物资。分离时优先保明确只有一个普通物资的一侧。每次按分离后新的 140° 夹内画面复审；仍看得见普通物资且有可保留侧时继续，每批最多五次已受理的分离。第五次分出合法单件仍可送。投送得到视觉确认且下位完成退出后登记首件，未确认退出继续按首件处理。开局移堆单独记账。
- **后续运送**。搜索和选择要保留的物体时按核心物资、普通物资、伤员排序，在同类可选时优先明确单件。整爪已有 1～3 件纯材料（普通、核心可混装）就整批送物资区；只有一名伤员就送伤员区。含危险物、伤员混装、数量超限或归属不清的批次不能获得运送许可。
- **普通分离**。选定左/右保留爪后按现有机械动作分离，额外慢夹 20°。保留侧与目标类别只指导这次动作，最终类别、数量、物体编号和安全区由闭爪复审绑定。两类分离前试转、轻撞及按高度抬爪滤除均不启用。两侧归属都不清时沿既有释放和搜索出口处理。
- **通用流程对齐**。停稳复审内保留漏检证据，物理分离后重新取证；空爪丢目标时可抬到 120° 原地重选；区内候选区分已下发接近距离与尚未下发的情况。开局进攻返程的物理完成回包、残差修正及防守返搜已对齐。决赛的 83° 投送动作独立于分离。

上述机械动作已核对下位源码，现场固件身份和实际分出最外侧物体的成功率须由实车确认。[两端接口](CROSS_REPO_REQUESTS.md)
